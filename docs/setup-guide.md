# 连接 Nintendo Switch 2

## 链路一：手机 HDMI 输出 + HDMI 采集卡（推荐）

```
小米 17 (USB-C, DP Alt Mode)
   └─ USB-C 扩展坞（带 HDMI 输出）
        └─ HDMI 线
             └─ HDMI 采集卡（UVC，免驱）
                  └─ USB-C / USB-A
                       └─ Nintendo Switch 2
```

### 采集卡怎么选（这一步最容易踩坑）

**1. 必须是标准 UVC（USB Video Class）、免驱的型号。**

Switch 2 对摄像头的兼容性偏保守：很多新款高清摄像头因为上报的模式太多，反而**无法识别**。
社区经验是「支持 UVC + 只提供 480p / 720p / 1080p 几种简单模式」的采集卡更容易被认出来。

**2. 必须能输出 1080p（或更低）。**

⚠️ **如果采集卡上报 2K / 1440p 及以上的模式，Switch 2 直接不识别。**
不少采集卡支持在多档分辨率之间切换，把它的开关拨到 1080p 就好了。

**3. 输出建议设为 1080p30 或 720p30**，与本应用固定的 30fps 对齐。

### 手机端要点

1. **小米 17 支持 USB-C DisplayPort 输出**（USB 3.2 Gen2 + DP Alt Mode），有线 HDMI 方案可行。
   若插上扩展坞后外屏无画面，检查系统「USB 用途」里是否误选成了「仅充电 / 传输文件」。
2. 手机屏幕比例是 **19.5:9**，横屏时 HDMI 输出的也是这个比例，采集卡送进 Switch 2 后可能被拉伸或裁切。
   此时打开应用内的 **`AF/AE → 16:9框`**：预览会被限制在屏幕中央的 16:9 区域、四周留黑，
   采集卡收到的就是标准 16:9 画面。
3. 延迟构成：手机端（约 120ms）+ 采集卡（约 30~100ms）+ Switch 2 合成。用于 GameChat 视频通话完全够用。

## 链路二：手机直接作为 UVC 摄像头（无需采集卡）

Android 原生支持「USB 用作 → 网络摄像头（Webcam）」模式（Pixel 机型在 Android 16 上已确认能被 Switch 2 直接识别）。
部分 HyperOS / 定制 ROM 可能没有该选项，可以：

- 下拉通知栏看「USB 用途 / USB 偏好」里有没有「网络摄像头」；或
- 在开发者选项里找相关开关。

如果有，手机可以直接用 USB-C 数据线连 Switch 2，不需要采集卡。此时 PureCam 负责的仍然是
「输出干净、全屏的画面」——系统会把屏幕内容作为 UVC 视频流送出去。

## 排查清单

| 现象 | 检查 |
| --- | --- |
| Switch 2 完全不识别 | **先确认采集卡不是 2K/1440p 模式**（这是最常见原因）；换一个已知可用的 UVC 设备交叉验证；优先选支持 480p 的产品；插底座而非机身试试 |
| 有画面但比例怪异 / 被裁 | 打开应用内 `16:9框` 输出模式；若仍变形见 [calibration.md](calibration.md) |
| 画面被转了 90° | 点一次「画面旋转」（转 90°）即可摆正，会自动记忆。若转了 180°，点两次 |
| 画面上下颠倒 | 扩展坞 / 采集卡安装方向导致时，点两次「画面旋转」（180°） |
| 画面被拉高 / 压扁 | 打开「校准图」，用「拉伸 ±」调到圆变正圆，常见值 0.75（见 [calibration.md](calibration.md)） |
| 画面模糊 / 只剩中间一小块 | 正常情况下日志里 `scale` 应为 **1.875**（填充）/ **0.776**（完整）。明显偏离请 `adb logcat \| grep PureCamDbg` 反馈 |
| 切了后置焦段画面不变 | v3 之前是 CameraX 无法路由物理子摄（已知根因，已修复）。现用 Camera2 `OutputConfiguration.setPhysicalCameraId`；某颗镜头被拒时会提示并自动从列表剔除 |
| 屏幕自己变黑了 | 息屏保护生效（默认 60s 无操作）。**投屏画面不受影响**，摸一下手机屏就亮。想彻底关掉就点「息屏保护」 |
| 提示条一闪而过看不清 | 自定义提示条默认停留 1.2s；错误类提示停留 3~4s |
| 画面卡顿 | 采集卡是否支持 30fps；手机是否过热降频（相机长时间预览会发热，建议拆壳通风） |
| 一会就黑屏 | 应用已开启屏幕常亮；若仍黑屏，检查系统省电策略是否冻结了应用，把 PureCam 加入后台豁免 / 电池无限制 |
| 装不上 / 覆盖安装报错 | 不同来源的包签名不同，先 `adb uninstall com.purecam.app` |

调试开关：`adb logcat | grep PureCamDbg` 可看到状态机跳转、分辨率回调，以及每次变换下发的
`view / buf / surf / sensor / display / net / fix / rot / eff / scale / front / sy`。
