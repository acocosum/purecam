# PureCam

把 Android 手机变成一个「纯净的全屏相机画面输出源」——通过 USB-C（DP Alt Mode）扩展坞输出 HDMI，
经 HDMI 采集卡接入 Nintendo Switch 2，作为其 USB 摄像头使用（GameChat / 支持摄像头的游戏）。

```
小米 17 ──USB-C 扩展坞(HDMI)──> HDMI 线 ──> 采集卡(UVC) ──USB──> Switch 2
```

相机素质比绝大多数桌面摄像头好得多，还能切超广角 / 长焦。这个 App 负责的只有一件事：
**让 HDMI 输出一份干净、比例正确、可调的相机画面。**

## 功能

| 功能 | 说明 |
| --- | --- |
| 全屏预览 | 自建 `TextureView`，旋转 / 填充 / 适配 / 拉伸补偿由一个矩阵统一控制 |
| 三层 UI 状态机 | 纯净画面 → 悬浮图标 → 完整面板。不操作时屏幕上**没有任何 UI** |
| **垂直拉伸补偿** | 0.50~1.50 可调（预设 1.00 / 0.75 / 0.80 / 1.33），抵消采集卡造成的画面拉长，自动记忆 |
| **校准图案** | 叠加标准正方网格 + 同心圆，一眼看出链路是压扁还是拉高 |
| 画面模式 | **填充**（16:9 裁满） / **完整**（4:3 全画幅，拿满传感器视野） / **16:9框**（限制在中央 16:9 区域） |
| 多摄像头切换 | 枚举逻辑摄像头 + 全部**物理子摄**（超广角 / 长焦 / 前置），按 35mm 等效焦距命名，记住上次选择 |
| **自动息屏保护** | 60 秒无操作关掉屏幕背光，**投屏画面完全不变**（只关背光、不改 framebuffer），触摸即恢复 |
| **低延迟管线** | 后处理压到 `FAST` 档（去掉时域降噪的多帧延迟）+ 关电子防抖，省约 33~66ms |
| 画面旋转 | 0/90/180/270 循环微调，兜底个别设备 Surface 旋转量不是 90° 的情况 |
| 对焦 / 曝光 | 连续 AF + AE，支持曝光补偿、中心对焦、**AF-L 对焦锁定**（固定机位必备） |

固定 30fps · 强制横屏 · 屏幕常亮 · 沉浸式全屏。

## 使用前提

- **采集卡必须能输出 1080p（或更低）**。⚠️ 上报 2K / 1440p 模式的采集卡，**Switch 2 不识别**。
- 采集卡必须是**标准 UVC、免驱**型号。
- 应用**只在小米 17 上验证过**。其他机型大概率能用，但没测过。

详见 [连接与排查](docs/setup-guide.md)。

## 安装

### 下载 APK

到 [Releases](../../releases) 页面下载 `PureCam-release.apk`，手机上点击安装。


### 自行编译（推荐）

需要 JDK 17 + Android SDK（platform 34 / build-tools 34）。

```bash
# 在 local.properties 里填上你的 SDK 路径
sdk.dir=<你的 Android SDK 路径>

./gradlew assembleDebug      # 调试包
./gradlew assembleRelease    # 发布包
```

**不需要任何额外配置** —— 仓库里没有签名密钥时，`assembleRelease` 会自动回退到 debug 签名。
想用自己的正式签名见 [keystore/README.md](keystore/README.md)。

> 换包来源（签名会不同）前需要先卸载旧版，见 [keystore/README.md](keystore/README.md)。

## 怎么用

```
[纯净画面] --点画面--> [悬浮图标] --点图标--> [完整面板]
     ^                     |                      |
     |                     | 3 秒无操作自动淡出    | 点「隐藏」或面板外的画面
     +---------------------+----------------------+
```

- **纯净画面**：只有相机画面，屏幕上没有任何 UI。点一下 → 右上角出现悬浮图标。
- **悬浮图标**：3 秒无操作自动淡出。点它 → 展开完整面板。
- **完整面板**：`切换摄像头` / `画面旋转` / `息屏保护` / `AF/AE`（二级菜单）/ `隐藏`
- 点面板内的**灰色空白区域不会有任何反应**（防误触）；只有点**面板外的画面区域**才会收起面板。

### 第一次用建议这样调

1. 接好链路，确认 Switch 2 能识别到画面。
2. 打开 `AF/AE → 校准图`，在 Switch 2 上看圆是不是正圆。
   不是就用 `拉伸 −/+` 调（**被拉高就调到 0.75 左右**，这是最常见的情况），见 [校准指南](docs/calibration.md)。
3. 视需要切 `填充 / 完整`：想拿满传感器视野（左右带黑边）选**完整**（4:3 全画幅）。
4. 摆好机位后点 `AF/AE → 中心对焦`，再点 `AF-C 连续` 切成 `AF-L 锁定`，画面就不会反复对焦了。

## 已知限制

- **做不到「App 挂后台 + 前台干别的」**。HDMI 走的是屏幕镜像，App 退到后台，送出去的就是别的 App 画面了——这是架构决定的，不是实现问题。
- **只在小米 17 上验证过**，其他机型大概率能用但没测过。
- **采集卡必须能输出 1080p**，2K / 1440p 模式的卡 Switch 2 不识别。

其余限制（为什么不做手动对焦、`surfaceRotation` 硬编码等）见 [docs/limitations.md](docs/limitations.md)。

## 项目结构

```
PureCam/
├── app/src/main/java/com/purecam/app/
│   ├── MainActivity.kt        # 全屏/横屏 + 三层状态机 + 变换矩阵 + 息屏保护
│   ├── CameraController.kt    # Camera2：会话、物理子摄路由、分辨率、对焦曝光、低延迟
│   ├── CalibrationOverlay.kt  # 校准图案（正方网格 + 同心圆）
│   └── UiFactory.kt           # 动态构建按钮、圆角背景、着色
├── docs/                      # 文档（见上方「文档」表）
├── tools/                     # 非可视化验证脚本
├── keystore/                  # 放你自己的签名（*.jks 已被 gitignore）
└── README.md
```

技术栈：Kotlin · Camera2（**不用 CameraX**，原因见[开发笔记](docs/development-notes.md)）·
纯代码构建 UI，无 XML 布局、无 Material 依赖 · minSdk 29 / targetSdk 34。
